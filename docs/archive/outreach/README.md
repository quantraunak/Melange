# Outreach drafts

Nothing in this folder is sent by an agent. Raunak sends, or approves a batch and then
the agent sends. Fill the bracketed fields. Keep every message under 120 words; these
people read on their phones between classes.

The product is broad (any creative person). The first community is Chapman / Orange,
reached through the groups that already exist there. One file per channel:

- `01-film-students.md`: Dodge producers and directors with a project this semester
- `02-actors-crew.md`: actors and crew, where they already look
- `03-chapman-orgs.md`: production office, clubs, theatre, art, dance and music programs
- `04-photo-music-dance.md`: photographers, models, musicians, dancers (the fun half)
- `05-usc.md`: the same, adapted, for week five
