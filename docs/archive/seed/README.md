# Seeding the feed: 15 real projects in 7 days

The first time anyone opens Melange is the only chance with them. Before a stranger
sees the feed it needs fifteen real projects from real people. Those come from people
Raunak knows, as a favor, and that is the whole plan for the week.

- `people.md`: the list. One row per person. Raunak fills the first three columns;
  the rest get filled as it happens.
- `ask.md`: the text to send. Short, personal, one ask.
- `instagram.md`: how every project in the feed becomes a post the day it goes up.

Rule: nothing here is sent by an agent. Raunak sends.
